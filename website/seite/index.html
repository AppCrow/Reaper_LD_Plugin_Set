LD Tools

Marker für die Lichtshow, direkt in REAPER.

LD Tools sind vier kostenlose Werkzeuge für Lichtdesigner in REAPER, in einem Fenster: Marker aus MIDI-Noten setzen, Marker für den grandMA3-Import umbenennen, Markergruppen kopieren und das Tempo live messen.

Für macOS ladenFür Windows laden

Kostenlos und quelloffen (MIT). Für REAPER 7 auf macOS und Windows.

So sieht es aus

Was drin ist

Ein Fenster für alles

Drei Tabs zum Umbenennen, für MIDI-Noten und zum Kopieren, das Tempo oben im Kopf. Das Fenster sitzt unten in REAPER angedockt und öffnet mit REAPER.

Tempo live messen

Liest das Tempo aus einem Audio-Item auf zwei Nachkommastellen, auch während REAPER spielt. „Half“ und „Double“ korrigieren die Oktave, „Set project tempo“ übernimmt den Wert, ohne dass Items verrutschen.

Marker aus MIDI-Noten

Jede Note wird ein Marker, eine Lane je Spur. Spuren mit gleichem Namen vor der Klammer, etwa „Kick (12)“ und „Kick (13)“, teilen sich eine Lane; vorhandene Marker darin werden auf Wunsch ersetzt.

Umbenennen für grandMA3

Baut Namen im Format Cue(Nummer)[Command]^Sequenz^ für eine ganze Auswahl auf einmal, mit Vorschau. Cue-Nummern zählen in der Reihenfolge, in der du klickst.

Marker kopieren

Eine Gruppe Marker samt Namen, Farbe und Abständen an eine andere Stelle kopieren, etwa für den Refrain, der wiederkommt.

Installation in REAPER

Ein Skript in REAPER legt alles ab: Skripte, Actions und die zwei nötigen Erweiterungen. Tastenkürzel schlägt es vor, setzen tust du sie selbst.

Häufige Fragen

Was brauche ich?

REAPER 7, für die Marker-Lanes REAPER 7.72 oder neuer. Die Erweiterungen ReaImGui und js_ReaScriptAPI liegen bei, der Installer legt sie ab. SWS brauchst du nicht.

Warum kein normaler Installer?

Nur ein Skript in REAPER kann Actions anlegen und den Dialog für Tastenkürzel öffnen. Darum installierst du LD Tools aus REAPER heraus. Nach dem Installieren der Erweiterungen REAPER einmal neu starten.

Was ist MA-Tools-Syntax?

Ein Markername wie Kick(1)[Top]^Kick^: Cue-Name, Cue-Nummer, Command und Sequenz. Das ist das Format, das der Marker-Import der grandMA3 liest.

Mein Tastenkürzel löscht die Auswahl. Warum?

Ist der Region/Marker Manager im Vordergrund, schluckt er das Kürzel. Klick zuerst in den Arrange-Bereich, dann das Kürzel.

Wie genau ist die Tempomessung?

In meinem Test mit einem echten Song lag sie weniger als 0,02 BPM daneben.

Wie komme ich zu einer neuen Version?

Neue Version laden und den Installer erneut ausführen. Einen automatischen Hinweis auf neue Versionen gibt es nicht.

Datenschutz in kurz

Der Code von LD Tools greift nicht aufs Internet zu. Es gibt kein Konto, keine Nutzungsstatistik und keine Absturzberichte. Gespeichert wird nur auf deinem Computer: in deinem REAPER-Ordner die Skripte, die Actions, die beiden Erweiterungen und ein paar Einstellungen wie der zuletzt offene Tab und die zuletzt benutzte Farbe, in deinem Projekt die Marker.

Die beiliegenden Erweiterungen ReaImGui und js_ReaScriptAPI sind unveränderte Fassungen ihrer Autoren; ihr Netzverhalten habe ich nicht eigens geprüft. Der Download kommt von GitHub, dafür gelten die Datenschutzbestimmungen von GitHub.
